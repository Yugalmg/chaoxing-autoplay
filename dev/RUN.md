# 视频代挂 · 使用说明

## 一条命令开刷

```bash
node autoplay.mjs --course "形势与政策"
```

跑完自动退出，日志写 `log/autoplay.log`，进度存 `state/progress.json`，中断后重跑自动跳过已通过的。

## 常用参数

| 命令 | 作用 |
|---|---|
| `--list` | 列出所有课程进度，决定先刷哪门 |
| `--course "X" --dry` | 只算计划，不播放（不碰网络业务接口） |
| `--course "X"` | 开刷 |
| `--course "X" --max-hours 6` | 跑满 6 小时自动收工（默认 8） |

课程名支持模糊匹配，`形势`、`劳动`、`人工智能` 都行。

## 内置的四个防坑机制

| 坑 | 处理 |
|---|---|
| 视频不在视口内不加载 | 每次驱动前 `scrollIntoView` |
| `video.play()` 被拦截 | 走 `videojs.getPlayer('video').play()` |
| 播放器在服务端进度处锁死 | 停滞时大跨度 seek 解锁 |
| 多进程同时驱动同一页面互踩 | pid 锁文件，第二个实例直接退出 |

## 判定标准

只认服务端：每刷完一个视频回读一次 `knowledge/cards`，`isPassed === true` 才计入完成。DOM 到片尾但服务端没认的，会留在待刷队列里，下一轮重试。

## 需要人工介入的边界

| 情况 | 表现 | 处理 |
|---|---|---|
| cookie 过期（12 小时） | 请求返回登录页 | 重新导出 cookie（`dump_cookies.mjs`） |
| 视频卡死超过 14 次 | 日志 `长时间无法推进，跳过` | 该视频单独排查 |
| 随机人脸抓拍 | 当前 539 个视频 **0 个启用** | 暂不涉及 |
| 习题 / PPT / 讨论 | 不在本脚本范围 | 见下 |

## 习题：预留开关，默认关

习题需要 AI 介入（题库匹配 + 语义判断），做成独立模块后接进 `autoplay.mjs` 的主循环即可。当前版本只处理 `type === 'video'` 的任务点，其余类型原样跳过。

## 零 token 说明

本脚本是**确定性程序**，运行时不需要任何 AI 调用。选定课程 → 运行 → 睡觉 → 早上看日志。
