## 五、开火前还差的最后一步

**player 模块**：用 `lib/cdp.mjs` 启动 headless Chrome → 灌 cookie → 打开 `studentstudy?chapterId=...` → 找到 iframe 内的 `video` 元素 → `playbackRate=1.5` + `play()` → 轮询 `.ans-job-finished` → 自动下一章。

其中「切窗口检测」的处理方式：headless 下页面可见性恒为 `visible`，再叠加定时 `mousemove` 与 `focus` 事件，抵消 142 个视频的失焦暂停。
